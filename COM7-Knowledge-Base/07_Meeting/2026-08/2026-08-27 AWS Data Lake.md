## สาระสำคัญ

### 1. Client VPN พร้อมแล้ว

การเชื่อมต่อ Client VPN **พร้อมต่อได้เลย** — ทีม AWS จะดำเนินการขั้นตอนต่อไป
→ [[Network & VPN]]

### 2. PDPA — ปิดประเด็นแล้ว

AWS ชี้แจงว่า **minimum requirement service อยู่ที่ไทยทั้งหมด** จึงตัดปัญหาเรื่อง PDPA ไปได้

**ยกเว้น 2 ตัว:**

| Service | ใช้ทำอะไร |
|---|---|
| **Macie** | detect ข้อมูล sensitive / personal |
| **SNS** | แจ้งเตือนผลจาก Macie |

สองตัวนี้ยังไม่อยู่ที่ไทย → ต้องพิจารณาแยกว่ากระทบ PDPA อย่างไร

> **Correction (2026-09-16):** ตรวจ endpoint จริงภายหลัง — **SNS มีที่ ap-southeast-7 แล้ว** (บันทึกจากประชุมคลาดเคลื่อน) · เหลือแค่ **Macie** ที่ยังไม่มีที่ไทย → ดู [[AWS Services]] · [[Decisions|D-19]]
→ [[Consent & PDPA]] · [[AWS Services]]

### 3. QuickSight ยังไม่มีแผนเปิดที่ไทย

กระทบการเลือกเครื่องมือ BI → [[Analytics & AI]] · [[Decisions]]

## ที่ต้องดำเนินการต่อ

### 1. ทีม AWS เชื่อมต่อกับเครื่อง 250 แบบ full load

ประสานงานกับพี่คองได้เลย โดยขอให้ทดสอบตามนี้

#### 1.1 แบ่ง ETL เป็น 2 scenario

| Scenario | ลักษณะ |
|---|---|
| A | data ที่ **ต้อง clean ก่อน** |
| B | data ที่ **พร้อมใช้งานเลย** |

การเขียน ETL pipeline ของสองแบบ**ไม่เหมือนกัน** → [[ETL & Spark]]

#### 1.2 ต้องมี log ทุกครั้งที่ ETL ขึ้น AWS

ต้องบอกได้ว่า:

| ต้องรู้ | รายละเอียด |
|---|---|
| **ปริมาณต้นทาง vs ปลายทาง** | ต้นทางมีกี่ column / กี่ row / ขนาดเท่าไร → ปลายทางได้ผลเหมือนกันไหม |
| **เวลา** | เวลาเริ่ม และเวลาเสร็จ |
| **โหมดเขียน** | เป็น **append** ข้อมูลที่ยังไม่มี หรือ **rewrite** ทั้งหมด |
| **ชื่อตาราง** | ระบุชื่อตารางต้นทางและปลายทาง |

#### 1.3 Schedule

ตั้งเบื้องต้นเป็น **23:30 น. ของทุกวัน**

#### 1.4 ผู้รับ log

MIS จะส่งอีเมลให้ทีม AWS ว่าจะส่ง log ให้ใครบ้าง

### 2. เครื่องมือทดแทน SSMS

MIS ถามว่ามี tool / service ของ AWS ตัวไหนทดแทนหรือเทียบเคียง **SQL Server Management Studio (SSMS)** ได้
**ทีม AWS จะไปหาคำตอบให้**

### 3. Query Editor เชื่อมฐานต้นทางได้ไหม

Query Editor ของ AWS เชื่อมกับ database ต้นทางโดยตรงได้หรือไม่
**ทีม AWS จะไปหาคำตอบให้**

### 4. ขอสรุป Minimum Tools

ขอให้ AWS สรุปออกมาว่ามีเครื่องมือขั้นต่ำอะไรบ้าง · แต่ละตัวทำอะไร · **ถ้าไม่มีจะทำ process ไหนไม่ได้**
