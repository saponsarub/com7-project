## 2. EV7 Taxi Tracking Map

แผนละเอียด → **[[EV7 Taxi Tracking Map]]**

**จุดประสงค์:** นำขึ้น production ให้ user ใช้ · ข้อมูล GPS แบบ realtime

| หัวข้อ | สิ่งที่ Manager ต้องการ |
|---|---|
| ข้อมูล | dashboard เดิมใช้ข้อมูลที่มีโหลดแบบ batch · ของจริงอาจต้องต่อ database ตรง ให้ใกล้ realtime ที่สุด · อาจต้องใช้ Kafka |
| ขนาด | พิกัด lat/long อาจมหาศาล → ออกแบบรองรับ big data |
| ธุรกิจ | หาโอกาสใหม่ — จุดที่มี EV ใช้บริการเยอะ · จังหวัดที่มีศักยภาพ · อนาคตเปิดปั๊ม EV · สาขาต่างจังหวัด · cross-sell กับธุรกิจอื่น |
| ติดตามรถผิดสัญญา (ไม่จ่ายค่างวด) | รถจอดอยู่ไหม · ติดไฟแดงหรือเปล่า · อยู่บนถนนไหม · **ถ้าตัดสัญญาณรถจะอันตรายไหม** |
| ความแม่นของพิกัด | ทศนิยม 4 ตำแหน่ง คลาดได้ ~10 เมตร อาจไม่ตกบนถนนพอดี → ข้อแรก: เทียบพิกัดรถกับพิกัดถนน หรือใช้ regression คำนวณความน่าจะเป็น |
| รถที่หนี | อาจถอด GPS หรือขับหนีออกต่างจังหวัด → วิเคราะห์ว่าจะไปไหน · ทำนายทิศทางปลายทาง · แสดงต้นทาง-ปลายทาง · ทิศหัวรถ / effect ทิศที่เคลื่อนที่ บนแผนที่ |
| การแสดงผล | เน้น track **รายคัน** · ไม่ต้องแสดงทั้งหมด (ข้อมูลเยอะ) · มีตัวเลือกแสดงทั้งหมดภายหลัง |
| ลำดับงาน | **เว้นเรื่อง realtime ไว้ก่อน** ใช้ข้อมูลที่มี แต่**ออกแบบและวางแผน realtime ไว้แล้ว** · ทำข้ออื่นก่อน พร้อมแล้วค่อยต่อข้อมูลจริง |
