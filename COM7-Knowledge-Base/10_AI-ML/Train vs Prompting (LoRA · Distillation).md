# Train vs Prompting (LoRA · Distillation)

เมื่อไหร่ต้อง "เทรน" เมื่อไหร่แค่ "เขียน prompt" · ศัพท์ที่ใช้ในงาน [[EV7 Taxi - Q&A Notebook (Kaggle)]]

## สองวิธีทำให้ AI ทำงานของเรา

| | Prompting (in-context learning) | Train / Fine-tune |
|---|---|---|
| เปลี่ยนอะไร | ข้อความที่ส่งไปพร้อมคำถามทุกครั้ง | น้ำหนัก (weights) ในตัวโมเดล |
| ต้องมี | คำอธิบายข้อมูล + ตัวอย่างไม่กี่ข้อ | คู่ "คำถาม → คำตอบที่ถูก" หลายร้อย–พันข้อ + GPU + เวลา |
| แก้ไข | แก้ข้อความ รันใหม่ทันที | เทรนใหม่ |
| เหมาะกับ | สอนให้รู้จักข้อมูล/กติกา | สอนรูปแบบ/ทักษะเฉพาะที่ prompt ทำไม่ได้ · ทำให้โมเดลเล็กเก่งเท่าโมเดลใหญ่ |
| เปรียบ | ยื่นคู่มือให้ผู้เชี่ยวชาญอ่านก่อนตอบ | ส่งพนักงานไปเรียนคอร์สจนจำได้ |

**ลำดับที่ควรลอง:** prompt ดี ๆ → few-shot (ตัวอย่างใน prompt) → tool / RAG → fine-tune · เทรนเป็นทางเลือกสุดท้าย

## ศัพท์

| คำ | ความหมาย |
|---|---|
| **Backbone / Base model** | โมเดลที่คนอื่นเทรนมาแล้ว รู้ภาษาอยู่แล้ว เราโหลดมาใช้ต่อ |
| **Embedding** | แปลงข้อความเป็นเวกเตอร์ · ความหมายคล้าย = ใกล้กัน (MiniLM) |
| **Classifier** | โมเดลเล็กทายประเภท (LogisticRegression บน embedding) · เทรนไม่กี่วินาที |
| **Fine-tune** | เทรนต่อจาก backbone ด้วยข้อมูลของเรา |
| **LoRA** | fine-tune แบบแปะชั้นเล็ก (~0.5–1% ของโมเดล) แล้วเทรนเฉพาะชั้นนั้น · ไม่แตะน้ำหนักเดิม · ไฟล์ adapter หลักสิบ MB |
| **QLoRA / 4-bit** | บีบ backbone เหลือ 4 บิตก่อนติด LoRA → เทรน 7B บน GPU ฟรีได้ |
| **Distillation** | ให้ AI ตัวใหญ่ (Claude) สร้างข้อมูลสอน → เทรน AI ตัวเล็ก (Qwen) · ได้โมเดลเล็ก เร็ว ถูก ที่เก่งงานเฉพาะ |
| **Label mask** | ตอนเทรนให้โมเดลเรียนเฉพาะคำพูดของ assistant ไม่เรียนคำถาม/ผล tool |
| **Overfit** | โมเดลจำประโยคแทนที่จะเข้าใจ · กันด้วยการแบ่ง test ตาม "สำนวน" ที่ไม่เคยเห็น |
| **Eval set** | ชุดข้อสอบแยกจากชุดสอน ใช้วัดผลก่อน/หลัง |

## ในงานเรา ตรงไหนเทรน ตรงไหนไม่เทรน

| ส่วน | เทรนไหม | หมายเหตุ |
|---|---|---|
| ส่วน 5 classifier ประเภทคำถาม | ✅ ไม่กี่วินาที | ชุดสอนแต่งจากแม่แบบ |
| ส่วน 8 LoRA Qwen 1.5B → JSON | ✅ แต่เลิกใช้ | จำแม่แบบ · ใช้จริงแย่ |
| cell 10 / 13 Qwen 3B / 14B | ❌ prompting | 14B แบบไม่เทรน: ช้า 12–55 วิ · แต่งตัวเลข |
| cell 15–16 Qwen 7B text-to-SQL | ✅ LoRA + distillation | ก่อนเทรน 6% → ดู [[Text-to-SQL Fine-tune (EV7 Taxi)]] |

## บทเรียน

- ชุดสอนที่แต่งจากแม่แบบน้อย ๆ → โมเดลจำแม่แบบ (ส่วน 8) · ต้องหลายสำนวน + พิมพ์ผิด + ตรวจคำตอบกับข้อมูลจริง (cell 15)
- วัดผลต้องใช้สำนวนที่โมเดลไม่เคยเห็น ไม่งั้นได้ 100% หลอก
- ความรู้ที่เปลี่ยนบ่อย (ราคา นิยาม นโยบาย) ใส่ผ่าน tool / RAG ไม่ใช่เทรน
