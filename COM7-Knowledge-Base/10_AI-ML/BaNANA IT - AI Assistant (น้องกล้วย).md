# BaNANA IT - AI Assistant (น้องกล้วย)

วิเคราะห์ผู้ช่วย AI ในแอปของทีม BaNANA IT จากภาพหน้าจอ · **ไม่เห็นชื่อผู้ให้บริการ LLM หรือที่ deploy ในภาพ** → ส่วนที่เป็นการคาดเดาติด `[อนุมาน]`

## สิ่งที่เห็นในภาพ

| เห็น | หมายความ |
|---|---|
| เลือกแบรนด์ BaNANA / Studio7 | ระบบเดียว แยกบุคลิก+ฐานความรู้ตามแบรนด์ |
| ชื่อ "น้องกล้วย" · หัวข้อ "ที่บอกให้ลูกค้า:" | ผู้ใช้คือพนักงานหน้าร้าน (ผู้ช่วยขาย) |
| ตอบชื่อสินค้า + SKU + ราคา + ส่วนลด | ต่อข้อมูลสินค้าจริง |
| ขอบเขต: รายละเอียดสินค้า · สต็อก · สาขาใกล้สุด · โปรโมชั่น · คำแนะนำการขาย · ประกาศ/คู่มือ vrcom7 · UFund · BaNANA Solar | ข้อมูลโครงสร้าง + เอกสาร |
| ตอบความรู้ทั่วไป (FPS 1080p) · ตารางเปรียบเทียบ | ความรู้ในตัว LLM |
| ปฏิเสธ "query ยอดขายสาขาพารากอน" และ "เทียบราคาเจ้าอื่น" | ขอบเขตใน system prompt · ไม่ต่อข้อมูลยอดขาย |
| ไมค์ + โหมดเสียง · ปุ่มสแกน | พูดได้ · สแกนบาร์โค้ด/รูป `[อนุมาน]` |
| 👍👎 · ปุ่มคำถามต่อ · "ให้ผมตั้งสติแป๊บ" | เก็บ feedback · แนะนำคำถาม · สถานะระหว่างรอ/streaming |

## สถาปัตยกรรมที่น่าจะเป็น `[อนุมาน]`

LLM เชิงพาณิชย์ผ่าน API (ไม่ได้เทรนเอง) + system prompt ต่อแบรนด์ + **tool** เรียก API สินค้า/ราคา/สต็อก/สาขา/โปรโมชั่น + **RAG** เอกสาร vrcom7/คู่มือ/UFund/Solar → แนวเดียวกับ cell 11 (Claude + tools) ของ [[EV7 Taxi - Q&A Notebook (Kaggle)]] · อธิบายกลไกใน [[How AI Assistant Works (Tool + RAG)]]
เหตุผล: ไทยลื่น · ทำตารางดี · มีความรู้ทั่วไป · มีโหมดเสียง · ปฏิเสธ query ยอดขาย (= tool แบบปุ่มตายตัว ไม่ใช่ให้ LLM เขียน SQL)

## จุดอ่อนที่เห็น

- คำตอบแรก: GALAX **GTX 1660** 6GB GDDR5 6,990 บาท · คำตอบถัดมา: "GTX 1660 ของ GALAX 2 รุ่น" แต่แสดง **GTX 1660 SUPER** 9,500 / 7,990 คนละ SKU → ค้นสินค้าไม่ครบ หรือ LLM รวมรุ่น
- ชิปแนะนำ "สินค้าไหนขายดีที่สุดในสัปดาห์นี้" แต่บอทเพิ่งปฏิเสธเรื่องยอดขาย

## ทดสอบในแอป 2026-10-16 → แหล่งข้อมูลน่าจะเป็นแบบไหน

| ถาม | ผล | แปลว่า `[อนุมาน]` |
|---|---|---|
| มีการ์ดจอทั้งหมดกี่รุ่น | "มีทั้งหมด 3 รุ่น" (ผู้ทดสอบเห็นว่าน้อยเกินจริง) · ถามต่อได้ชุดราคาไม่ตรงกับรอบแรก (รุ่นเด่น Galax 6,500 แต่อีก 2 รุ่น 10,000+) | tool ค้นสินค้าคืน**แค่ไม่กี่รายการที่ตรงที่สุด** (top-k) ไม่ใช่ทั้ง catalog · ไม่มี tool นับ/รวม · LLM เข้าใจผิดว่าผลค้นคือทั้งหมด · แต่ละรอบค้นใหม่ได้ชุดต่างกัน → ขัดกันเอง |
| GTX 1660 SUPER สาขาสยามมีของไหม | "ขณะนี้ไม่มีสต็อก" + เสนอรุ่นอื่น + แนะนำสาขา ICONSIAM | มี **tool เช็คสต็อกรายสาขาแบบ realtime** (API/SQL ระบบสต็อก) |
| สินค้าที่เพิ่งเข้าหน้าเว็บวันนี้ | ระหว่างรอขึ้น "กำลังหาข้อมูลจากระบบ" · ตอบลำโพง CMK 2,150 จาก 2,699 (ลด 549) · คำบรรยายคล้ายหน้าเว็บแต่ไม่ตรงคำต่อคำ | ข้อมูลสินค้า/ราคา**สดวันเดียวกัน** → tool ต่อ catalog/API จริง ไม่ใช่ RAG ที่ export เป็นรอบ · tool คืนคำบรรยายจากเว็บ แล้ว LLM เรียบเรียงใหม่ · ส่วนลด 549 LLM คำนวณเอง (ถูก) |

**สรุป:** tool ค้นสินค้า (catalog สด · คืนผลจำกัดจำนวน) + tool สต็อกรายสาขา (สด) + LLM เรียบเรียง · ยังไม่ชัดว่าเป็น API หรือ SQL ตรง
**จุดอ่อนเชิงออกแบบ:** ผลค้นถูกตัดแต่ LLM ไม่รู้ → ตอบ "ทั้งหมด 3 รุ่น" ผิด · แก้ได้โดยให้ tool คืน "พบ N รายการ แสดง 3" หรือมี tool นับ/กรองราคา · agent Taxi ของเราทำแบบนี้แล้ว (`(แสดง 30 จาก N แถว)`)

## ยืมมาใช้กับงานเรา

👍👎 (ได้ชุดวัดผลฟรี) · ปุ่มคำถามต่อ · ข้อความระหว่างรอ · ขอบเขตชัด · ถ้าระบบเขาเพิ่ม tool ได้ อาจต่อ agent Taxi เป็นอีกหมวดในแอปเดียวกัน
