# How AI Assistant Works (Tool + RAG)

อธิบายจากศูนย์ว่าแชตบอตที่ "รู้ข้อมูลบริษัท" ทำงานยังไง · ตัวอย่างเดินเรื่องด้วยคำถาม **"มีการ์ดจอรุ่นไหนบ้าง ผ่อน UFund ได้ไหม"** (แบบผู้ช่วยขาย [[BaNANA IT - AI Assistant (น้องกล้วย)]])
ตัวเลขสินค้าในตัวอย่างมาจากภาพหน้าจอ · เงื่อนไข UFund ในตัวอย่างเป็นข้อความสมมติ

## 0. หลักข้อเดียว

LLM (ChatGPT · Claude · Qwen) **เขียนภาษาคนเก่ง แต่ไม่รู้ข้อมูลบริษัท** และทำได้อย่างเดียวคือ "รับข้อความ → เขียนข้อความต่อ"
ทั้งระบบจึงมีงานเดียว: **หาข้อมูลที่ถูกมาแปะในข้อความ ก่อนให้ LLM เขียนคำตอบ** · ข้อมูลมา 2 ทาง

| ทาง | ข้อมูลแบบไหน | ตัวอย่าง |
|---|---|---|
| **Tool** (function calling) | มีโครงสร้าง: ตาราง / API | สินค้า ราคา สต็อก สาขา ตำแหน่งรถ |
| **RAG** (retrieval-augmented generation) | ข้อความ: เอกสาร | คู่มือ ประกาศ เงื่อนไข นโยบาย โน้ต Obsidian |

## 1. Tool — ให้ LLM "กดปุ่ม" ที่เราเตรียมไว้

**เตรียม (ครั้งเดียว):** เขียนฟังก์ชันธรรมดาที่ query ฐานข้อมูล + ใบอธิบายให้ LLM อ่าน (ชื่อ · ทำอะไร · ต้องใส่อะไร)

**ตอนถาม:**
1. แอปส่ง คำถาม + ใบอธิบาย tool ให้ LLM
2. LLM ตอบระบบ (ไม่ใช่ตอบคน): `ขอเรียก search_products(category="การ์ดจอ")`
3. **โปรแกรม** (ไม่ใช่ LLM) รันฟังก์ชันจริง → ได้ชื่อ SKU ราคา
4. ส่งผลกลับให้ LLM อ่าน

→ ตัวเลขในคำตอบมาจากฐานข้อมูล ไม่ใช่ LLM คิดเอง · LLM เห็นเฉพาะสิ่งที่ tool คืนมา

**tool 2 แบบ**

| แบบ | ตัวอย่าง | ข้อดี | ข้อเสีย |
|---|---|---|---|
| ปุ่มเฉพาะงาน | `search_products` · `check_stock` · `x_cars_in_area` | ปลอดภัย แม่น คุมได้ | ถามนอกปุ่มไม่ได้ |
| ปุ่มยืดหยุ่น (text-to-SQL) | `run_sql` ให้ LLM เขียน SQL เอง | ถามได้หลากหลาย | LLM อาจเขียนผิด → ต้องคุม/เทรน |

## 2. RAG — ค้นย่อหน้าที่เกี่ยวข้องมาแนบ

**เตรียม (ครั้งเดียว / เมื่อเอกสารเปลี่ยน):**
1. รวมเอกสาร → 2. หั่นเป็นชิ้น ~1 ย่อหน้า (chunk) → 3. แปลงแต่ละชิ้นเป็นเวกเตอร์ (embedding: ข้อความความหมายคล้าย = ตัวเลขใกล้กัน) → 4. เก็บใน vector database

**ตอนถาม:** แปลงคำถามเป็นเวกเตอร์ → หา 2–3 ชิ้นที่ใกล้ที่สุด → แนบไปกับคำถาม
เปรียบ: บรรณารักษ์เปิดหาหน้าที่ตรงคำถามมาให้ 2–3 หน้า ไม่ใช่อ่านทั้งห้องสมุด

## 3. ประกอบข้อความก้อนเดียวให้ LLM

```
[system prompt]  บุคลิก · กติกา · ขอบเขต (ห้ามเดาราคา · ห้ามตอบยอดขาย)
[คำถาม]          มีการ์ดจอรุ่นไหนบ้าง ผ่อน UFund ได้ไหม
[ผลจาก tool]     PNY GTX 1650 9,150 · GALAX GTX 1660 6,990 · OCPC RTX 2060 20,900
[เอกสาร RAG]     "UFund ผ่อนได้ ... งวด ..."
```

## 4. ทำไมคำตอบลื่นเป็นภาษาคน

| ปัจจัย | ทำยังไง |
|---|---|
| บุคลิก/น้ำเสียง | system prompt |
| รูปแบบ | สั่งให้ใช้ bullet/ตาราง · แอปแปลง markdown |
| ตัวอย่างคำตอบ (few-shot) | ใส่คำตอบดี ๆ 2–3 ตัวอย่างให้เลียนแบบ |
| ความรู้ทั่วไป | มาจากความรู้ในตัว LLM — **ไม่ได้ตรวจกับข้อมูล เสี่ยงผิดที่สุด** |
| ดูเร็ว | ส่งทีละคำ (streaming) + ข้อความระหว่างรอ |
| ชวนถามต่อ | เรียก LLM อีกรอบให้เดาคำถามถัดไป → ปุ่ม |

## 5. ภาพรวม

```
ผู้ใช้ ─► แอป ─► LLM รอบ 1: "ต้องใช้ข้อมูลอะไร"
                  ├─ tool ─► API / ฐานข้อมูล ─┐
                  └─ RAG  ─► vector DB ──────┤
                LLM รอบ 2: อ่านทั้งหมด → เขียนคำตอบ
        ◄─ แอปแสดงทีละคำ · ตาราง · 👍👎 · ปุ่มคำถามต่อ
```
