## 3. ความสมเหตุสมผล — เทียบกับที่วัดจริงใน PoC

### 3.1 ขนาดข้อมูล 10 → 20 → 30 TB ดูสูงกว่าที่วัดได้มาก

| แหล่ง | วัดจริง | ที่มา |
|---|---:|---|
| K2 + ITOS ข้อมูลธุรกิจ (Parquet) | **~8 GB** (+ ส่วนเสริม ~5 GB) | [[K2 + ITOS - Storage Sizing]] |
| ITEC `fact_sales_enriched` (Iceberg ที่ใช้จริง) | 3.4 GB (โฟลเดอร์ 108 GB เพราะไฟล์ค้างจาก DROP TABLE) | [[Glue Jobs (ap-southeast-7)]] |
| K2 ไฟล์รูป/PDF ถ้าย้าย | ~2.6 TB | [[K2 + ITOS - Storage Sizing]] |
| D365 raw ใน `syndpdev001` (Parquet · ไม่นับตารางสรุป/ซ้ำ) | **~28 GB** (SQL 234 GB) | [[D365 F&O - Storage Sizing]] |
| D365 / BC LS ไฟล์ใน ADLS | ยังไม่รู้ (ไม่มีสิทธิ์อ่าน) | [[ADLS Gen2 to S3]] |

→ ข้อมูลตารางที่วัดได้ **หลักสิบ GB ไม่ใช่หลัก TB** · 10 TB จะเป็นจริงถ้านับไฟล์เอกสาร K2 · ข้อมูลดิบหลายสำเนา (Raw/Bronze/Silver/Gold) · log · หรือแหล่งที่ยังไม่ได้สำรวจ — **ต้องขอที่มาของ 10 TB**

### 3.2 ค่าเก็บข้อมูลเป็นส่วนน้อยของบิล

S3 Standard 10 TB = ~$230/เดือน (**5%** ของ $4,859) · 30 TB = ~$691 (8%) → **อีก ~92–95% คือ compute / บริการอื่น** ซึ่งสไลด์ไม่ได้แยกให้เห็น · ถ้าขนาดข้อมูลจริงเล็กกว่ามาก บิลอาจไม่ลดตามเท่าไร เพราะส่วนใหญ่ไม่ได้ขึ้นกับขนาด

### 3.3 Direct Connect = 23% ของค่า cloud ทั้งหมด

78,000 บาท/เดือน × 120 เดือน = **9.36 ล้าน** (23% ของ 39.92 ล้าน)
- ข้อมูลที่ต้องส่งต่อวันน่าจะหลัก MB–GB (โหลด batch 23:30 ตาม [[Decisions]]) — Site-to-Site VPN อาจพอ (ค่า AWS ~1,000+ บาท/เดือนต่อ connection ไม่รวมค่าเน็ต) `[อนุมาน — ต้องวัดปริมาณรายวันจริง]`
- ตอนนี้ PoC ใช้ Client VPN อยู่แล้ว ([[2026-08-27 AWS Data Lake]])
- ถ้าจำเป็นจริง ใช้ 1 เส้น + VPN สำรอง แทน 2 เส้นได้ไหม

### 3.4 ฝั่ง On-premise อาจตั้งไว้สูงเกิน

- **50 ล้านสำหรับข้อมูล 10–30 TB** — ไม่มีสเปกให้ตรวจ (server กี่เครื่อง · storage · license) `[อนุมาน — สำหรับขนาดนี้ดูสูง ต้องเห็นใบเสนอราคาจริง]`
- On-prem นับ "ซื้อเผื่อ ใช้จริง ~33%" แต่ cloud สมมติโตแบบขั้นบันไดพอดี

### 3.5 สิ่งที่สไลด์ไม่ได้รวม (ทำให้ตัวเลข cloud ดูต่ำกว่าจริงได้)

| ไม่รวม | ทำไมสำคัญ |
|---|---|
| **AWS Support plan** | Business/Enterprise คิดเป็น % ของบิล |
| ค่าคนดูแล / Managed Service | สไลด์บอก "Managed Services ลดภาระทีม" แต่ไม่มีราคา |
| ค่าย้ายข้อมูลครั้งแรก | DMS full load · **Azure egress** (จ่ายฝั่ง Azure) · ค่าแรงทำ pipeline |
| DR / สำเนาข้าม region | สไลด์อ้าง Business Continuity แต่ไม่ได้คิดราคา |
| BI / Dashboard | **QuickSight ยังไม่มีใน Thailand** ([[2026-08-27 AWS Data Lake]]) — ใช้อะไรแทน ราคาเท่าไร |
| Macie | ไม่มีใน Thailand — PDPA scanning ใช้อะไร |
| ค่า query (Athena) · ค่า request · CloudWatch · KMS · NAT | ขึ้นกับการใช้งาน |
| ค่าเงิน / ราคาปรับขึ้น 10 ปี | คิด 33.66 บาท/USD คงที่ 10 ปี |
| ส่วนลด (Savings Plans · EDP · Credit PoC) | อาจทำให้ถูกลง — ควรขอ |
| ระบบเดิมที่ยังต้องจ่ายคู่ขนาน | Synapse/ADLS · K2 (ถึง Q1/2027) |

## 4. คำถามที่ต้องถามทีม AWS

### ก. ขนาดข้อมูลและที่มาของตัวเลข
1. 10 / 20 / 30 TB คำนวณจากอะไร — แหล่งไหนบ้าง · เป็นข้อมูลดิบหรือหลังบีบอัด · นับกี่ชั้น (Raw/Bronze/Silver/Gold)
2. รวมไฟล์เอกสาร/รูปของ K2 (~2.6 TB) ไหม
3. ทำไมโต 10 TB ทุก 2 ปี — อ้างอิงอัตราการโตจากอะไร
4. ถ้าขนาดจริงปีแรกแค่ 1 TB บิลจะเหลือเท่าไร (ขอ scenario)

### ข. รายละเอียดราคา AWS
5. ขอ **ลิงก์/ไฟล์ export ของ Pricing Calculator** แยกรายบริการ (S3 · Glue · DMS · Athena · Redshift? · EC2 · NAT · Lake Formation · CloudWatch …)
6. $4,859/เดือน — compute อะไรบ้าง ขนาดเท่าไร รันกี่ชั่วโมง/วัน (ETL รันวันละครั้ง 23:30 · ไม่ต้องเปิด 24 ชม.)
7. คิด DMS replication instance เปิด 24/7 ไหม · ขนาดอะไร
8. รวม Support plan หรือยัง · ระดับไหน
9. มีส่วนลดอะไรได้บ้าง — Savings Plans · EDP · Migration Acceleration Program (MAP) credit · credit จาก PoC
10. ราคา Thailand region ต่างจาก Singapore เท่าไร (ถ้า service ไหนไม่มีในไทยต้องไปใช้ region อื่น)

### ค. Network
11. ทำไมต้อง Direct Connect 1 Gbps **2 เส้น** — ปริมาณข้อมูลรายวันที่คาดคือเท่าไร
12. 78,000 บาท/เดือน แยกเป็นค่า port AWS กับค่าวงจร telco เท่าไร · ผู้ให้บริการรายไหน · สัญญากี่ปี
13. Site-to-Site VPN พอสำหรับ batch รายวันไหม — ถ้าเริ่มด้วย VPN แล้วค่อยเพิ่ม DX ได้ไหม

### ง. บริการที่ยังไม่มีใน Thailand
14. BI/Dashboard ใช้อะไร (QuickSight ยังไม่มีในไทย) — ราคารวมในสไลด์ไหม
15. Macie / PDPA data discovery ใช้อะไรแทน
16. ถ้าต้องใช้ service นอกไทย ข้อมูลออกนอกประเทศไหม (PDPA)

### จ. ฝั่ง On-premise
17. 50 ล้าน คือสเปกอะไร — ขอใบเสนอราคาหรือ BOM ที่ใช้เทียบ
18. On-prem 15 ปี = 111 ล้าน คิดยังไง (คำนวณได้ 113–120.5 ล้าน)
19. ทำไมสมมติซื้อเผื่อใช้ 33% แต่ cloud โตพอดีทุกช่วง — เทียบแบบเดียวกันได้ไหม

### ฉ. ต้นทุนที่ยังไม่อยู่ในสไลด์
20. ค่าย้ายระบบครั้งแรก (คน · DMS full load · Azure egress) ใครทำ ราคาเท่าไร
21. Managed Service / Partner ดูแลระบบ — ราคาเท่าไร ขอบเขตอะไร
22. DR — ต้องมีไหม ถ้ามีราคาเพิ่มเท่าไร
23. Training ทีม · ค่าเครื่องมือเสริม (monitoring · data catalog · data quality)

### ช. สัญญาและความเสี่ยง
24. ผูกสัญญากี่ปี · ถ้าลด/เพิ่มขนาดกลางทางได้ไหม
25. ตั้ง Budget / แจ้งเตือนค่าใช้จ่ายเกินยังไง ใครรับผิดชอบ
26. ถ้าวันหนึ่งจะย้ายออก ค่า egress ข้อมูลออกจาก AWS เท่าไร

## 5. ข้อสังเกตก่อนตัดสินใจ

- **ทิศทาง "cloud ถูกกว่า on-prem" น่าจะถูก** สำหรับข้อมูลขนาดนี้ — แต่**ตัวเลขทั้งสองฝั่งยังตรวจสอบไม่ได้** (ไม่มีรายละเอียดรายบริการ · ไม่มีสเปก on-prem)
- **ตัวที่ขยับผลมากที่สุด:** ขนาดข้อมูลจริง (วัดได้หลักสิบ GB ไม่ใช่ TB) · Direct Connect (23% ของทั้งหมด) · compute ที่ไม่ได้แยกให้เห็น (92–95% ของบิล AWS)
- ก่อนเซ็น ควรได้: Pricing Calculator แยกรายบริการ · scenario ขนาดจริง · ราคา VPN vs DX · ส่วนลดที่ได้ · ต้นทุนแฝงในหัวข้อ 3.5
