# EV7 Taxi - Business Questions

คลังคำถามที่ผู้ใช้แต่ละกลุ่มน่าจะถามระบบถามตอบ / dashboard · รวบรวมจาก [[EV7 Taxi - Spec Requirements & Gap]] (Spec v1.0) · [[EV7 Taxi Tracking Map]] (Phase 1–6) · [[EV Business]] (นโยบาย 4OD · Lineman/Grab · UFUND) · [[2026-10-12 Manager แนวทางทีม]] · คำถามจริงที่ผู้ใช้ทดสอบ
ใช้เป็น: ① ชุดทดสอบ (`eval_questions.csv`) ② แบบคำถามสำหรับสร้างชุดสอน (cell 15 `fam(...)`) ③ ลำดับงานว่าต้องขอข้อมูลอะไรเพิ่ม

**สถานะ** ✅ ตอบได้แล้ว และมีในชุดสอน · 🟡 ข้อมูลพอ แต่ยังไม่มีในชุดสอน (agent อาจทำได้ ต้องเพิ่ม `fam`) · 🔶 ต้องคำนวณเพิ่ม (เช่น ตาราง stops) · ⛔ ต้องขอข้อมูลเพิ่ม

## 1. Operation — ติดตามรถ (ทุกวัน)

| คำถาม | สถานะ | ต้องใช้ / ชุดสอน |
|---|---|---|
| ตอนนี้รถออนไลน์กี่คัน แยกสถานะ | ✅ | `fleet_now` |
| {จังหวัด/เขต} มีรถกี่คัน ว่างกี่คัน มีผู้โดยสารกี่คัน | ✅ | `status_now_prov` · `cars_now_bkk_dist` |
| แถว{จังหวัด}มีรถวิ่งอยู่ไหม | ✅ | `moving_now_prov` |
| {ทะเบียน} อยู่ไหน / วิ่งหรือจอด / มีผู้โดยสารไหม | ✅ | `car_where` |
| {ทะเบียน} วันนี้ไปไหนมาบ้าง ผ่านจังหวัดอะไร | ✅ | `car_provinces` |
| รถไม่มีสัญญาณกี่คัน อยู่แถวไหน | ✅ | `no_signal_now` |
| รถคันไหนไม่ส่งสัญญาณเกิน X ชั่วโมง | 🟡 | `points` (max ts ต่อคัน) |
| รถออกนอกเขตวันนี้กี่คัน ไปจังหวัดไหน | ✅ | `out_of_zone_day_where` |
| {ทะเบียน} ออกนอกเขตไหม ออกไปกี่ครั้ง | 🟡 | `points` |
| รถคันไหนจอดนานเกิน X ชั่วโมง (อาจเสีย/ทิ้งรถ) | 🔶 | ตาราง stops |
| รถคันไหนวิ่งเร็วเกิน 120 กม./ชม. | 🟡 | `points.speed` |
| รถเข้าศูนย์บริการ/อู่กี่คัน วันนี้ | ⛔ | พิกัดศูนย์บริการ (SMART) |
| รถคันไหนวิ่งเกินระยะต่อ 1 ชาร์จ → ต้อง recall (OP-1) | ⛔ | % แบต / ระยะต่อชาร์จ |
| ประวัติตัด/ต่อไฟของ {ทะเบียน} (OP-2) | ⛔ | ความหมาย `cm_engine` / `cm_battery` |

## 2. Collection / สินเชื่อ (นโยบาย 4OD · ลูกหนี้ค้างชำระ)

| คำถาม | สถานะ | ต้องใช้ |
|---|---|---|
| รถที่ค้างชำระเกิน 4 วัน ตอนนี้อยู่ไหน | ⛔ | ผูก `car_id` ↔ สัญญา + สถานะค้างชำระ (UFUND / EV7 Core) |
| {ทะเบียน} ตัดสัญญาณ/ตัดชาร์จตอนนี้ปลอดภัยไหม (จอดอยู่ ไม่ใช่วิ่ง) | 🔶 | สถานะ + ระยะจากถนน (Phase 3) · **การตัดต้องเป็นการตัดสินใจของคน** |
| {ทะเบียน} สัญญาณหายล่าสุดที่ไหน น่าจะไปทางไหน | ✅ | 7.2 `x_lost_signal` (คาดการณ์) |
| รถค้างชำระคันไหนออกต่างจังหวัด | ⛔ | สัญญา + `points` |
| สงสัยถอด GPS: สัญญาณหายกลางทางขณะวิ่ง | 🟡 | `points` (gap ขณะ speed > 20) |
| จุดจอดประจำของ {ทะเบียน} (บ้าน/อู่) | 🔶 | stops + ข้อมูลหลายสัปดาห์ |

## 3. Business & Marketing

| คำถาม | สถานะ | ต้องใช้ / ชุดสอน |
|---|---|---|
| {ทะเบียน} วิ่งไปกี่กิโล (วันนี้/เมื่อวาน) (BM-1) | ✅ | `car_km_day` |
| รถคันไหนวิ่งไกลสุด | ✅ | `longest_km_day` |
| ระยะทางรวมทั้งฝูง / เฉลี่ยต่อคันต่อวัน | 🟡 | `points` + `dist_km` |
| เส้นทางของ {ทะเบียน} (BM-2) | ✅ แผนที่ · 🟡 ข้อความ | dashboard |
| จุดที่จอดบ่อย จัดอันดับตามเวลาจอด ตัดศูนย์บริการ (BM-3) | 🔶⛔ | stops + พิกัดศูนย์บริการ |
| ช่วงเวลาไหนผู้โดยสารเยอะ | ✅ | `peak_hour_pickups` · `peak_hour_hired` |
| เขตไหนคนเรียกรถเยอะสุด | ✅ | `top_pickup_dist` |
| {จังหวัด} วันนี้รับผู้โดยสารกี่ครั้ง | ✅ | `pickups_prov_day` |
| รถคันไหนรับผู้โดยสารบ่อยสุด | ✅ | `top_cars_pickups` |
| {ทะเบียน} รับผู้โดยสารกี่ครั้ง | ✅ | `car_pickups` |
| อัตราการใช้งาน (% เวลามีผู้โดยสาร) ต่อคัน / ต่อจังหวัด | 🟡 | `points` |
| สัดส่วนรถวิ่ง/จอด | ✅ | `status_ratio` |
| ความเร็วเฉลี่ยใน{จังหวัด} | ✅ | `avg_speed_prov` |
| เทียบ{จังหวัด} 2 วัน ช่วงเวลาเดียวกัน (TL-2) | ✅ | `compare_days_prov` |
| เทียบกลุ่ม campaign กับกลุ่มอื่น: ระยะทาง/ผู้โดยสาร (TL-2/4/5) | 🔶 | ตาราง `groups` จากการ paste ทะเบียน |
| ใช้เกณฑ์เอง เช่น "จอดนาน = 30 นาที" (TL-1) | 🟡 | ใส่ในคำถามได้ · ยังไม่มีในชุดสอน |
| คนขับที่วิ่ง Lineman / Grab ต่างจากคนอื่นไหม | ⛔ | `taxi_lineman` / `taxi_grab` (EV7 Core) |
| สาขา COM7/BaNANA ไหนอยู่ใกล้จุดที่คนขับใช้เวลาเยอะ (cross-sell) | 🔶 | `rpt.dim_branch_itec` (มีพิกัด) |
| รายได้ต่อคัน / ต่อวัน | ⛔ | ข้อมูลรายได้ (ไม่มี) |

## 4. โครงสร้างพื้นฐาน EV (สถานีชาร์จ)

| คำถาม | สถานะ | ต้องใช้ / ชุดสอน |
|---|---|---|
| {จังหวัด} มีสถานีชาร์จกี่แห่ง | ✅ | `chargers_prov` (OSM บางส่วน) |
| ผู้ให้บริการไหนมีสถานีมากสุด | ✅ | `chargers_operator` |
| สถานีชาร์จใกล้ {ทะเบียน} | ✅ | `nearest_charger_car` |
| รถจอดอยู่ที่สถานีชาร์จกี่คัน | ✅ | `cars_near_chargers` (ประมาณจากระยะ) |
| จังหวัดไหนมีรถแต่ไม่มีสถานีชาร์จ | ✅ | `prov_no_charger` |
| ควรเปิดสถานีชาร์จเขตไหน | ✅ | `site_recommend` (ประเมินเบื้องต้น) |
| สถานีไหนรถเราใช้บ่อยสุด / ใช้เวลาชาร์จนานเท่าไหร่ | 🔶⛔ | stops ใกล้สถานี · ยืนยันการชาร์จต้องใช้ `cm_battery` |
| จำนวนสถานีจริง (EVAT 3,429) | ⛔ | ไฟล์ EVAT |

## 5. ผู้บริหาร — ภาพรวม

| คำถาม | สถานะ | ต้องใช้ |
|---|---|---|
| ฝูงรถ active กี่คัน (เทียบรถทั้งหมดในสัญญา) | 🟡⛔ | `points` · จำนวนรถในสัญญาจาก EV7 Core |
| จังหวัดไหนมีรถมากสุด / ศักยภาพสูงสุด | ✅ | `top_prov_now` · `top_dist_in_prov` |
| แนวโน้มการใช้งานรายสัปดาห์/เดือน | ⛔ | ข้อมูลย้อนหลังหลายสัปดาห์ |
| ขยายไปจังหวัดไหนดี | 🟡 | pickups + รถ + สถานีชาร์จ ต่อจังหวัด |

## 6. คุณภาพข้อมูล

| คำถาม | สถานะ | ต้องใช้ |
|---|---|---|
| มีข้อมูลวันไหนถึงวันไหน | ✅ | `data_range` |
| ตอน {เวลา} มีรถส่งสัญญาณกี่คัน | ✅ | `online_at_hour` |
| อุปกรณ์ไหนส่งข้อมูลถี่/ห่างผิดปกติ | 🟡 | `points` (gap ต่อคัน) |

## 7. ที่ต้องปฏิเสธ / ไม่มีข้อมูล (สอนให้ตอบสั้นและถูก)

| คำถาม | ตอบ |
|---|---|
| ดับเครื่อง / ตัดสัญญาณ / ล็อก {ทะเบียน} | ระบบตอบคำถามได้อย่างเดียว |
| แบตเหลือเท่าไหร่ · รายได้คนขับ · ข้อมูลคนขับ | ไม่มีข้อมูลนี้ (บอกว่าต้องขอจากไหน) |
| ถนน{ชื่อ} มีรถกี่คัน | ไม่มีชื่อถนน → เสนอใช้เขตแทน |
| อากาศ · หุ้น · เรื่องทั่วไป | ช่วยได้เฉพาะเรื่องรถ EV7 |
