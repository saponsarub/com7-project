## ⚠️ K2 ให้บริการทั้ง UFUND และ EV

ข้อค้นพบสำคัญที่สุดของฝั่ง EV: **K2 ไม่ได้เป็นระบบของ UFUND อย่างเดียว**

โมดูลของ EV ที่ใช้ K2:

| โมดูล | ทำอะไร |
|---|---|
| Billing & Repayment | ใบแจ้งหนี้และการชำระคืน |
| Overdue Bills | บิลค้างชำระ |
| Refund Orders | คำสั่งคืนเงิน |
| E-invoicing | ใบกำกับภาษีอิเล็กทรอนิกส์ |
| Consolidated Invoicing | ใบแจ้งหนี้รวม |
| Invoice Reversal | ยกเลิก/กลับรายการใบกำกับภาษี |
| Traffic Violation / Violation Mgmt | ค่าปรับจราจร |
| Cash Flow · Profit Analysis | ร่วมกับ 365 |

**สิ่งที่ต้องตรวจก่อนออกแบบ Silver layer:**

1. ตาราง `CONTRACT` / `INVOICE` / `REPAYMENT` ใน `HPCOM7` มีข้อมูล 2 ธุรกิจปนกันหรือไม่
2. ถ้าปน แยกด้วยคอลัมน์ไหน (`PROJECT_TYPE`? `SETUP_COMPANY`? อย่างอื่น?)
3. เกณฑ์ OD / ค่าปรับที่ทำไว้ให้ UFUND ใช้กับสัญญา EV ได้หรือไม่
4. ค่าปรับจราจรเก็บที่ตารางไหน — ยังไม่มีในเอกสาร K2 ปัจจุบันเลย

โครงสร้าง K2 → [[K2 Overview]] · [[K2 - Table Inventory]] · คำถามค้าง → [[Source System Issues]]

## ทำไมค่าปรับจราจรถึงอยู่กับใบแจ้งหนี้

จากรูปแบบธุรกิจเช่ารถ: เมื่อลูกค้าคืนรถ ต้องเข้าขั้นตอน**เตรียมรถ** ซึ่งบังคับให้เคลียร์ 3 อย่างก่อน

```
คืนรถ ──► เคลียร์ค่าปรับจราจร ──► เก็บยอดค้างชำระ ──► ตรวจสภาพ/ซ่อมบำรุง ──► ปล่อยเช่าต่อ
```

ค่าปรับจราจรจึงเป็น**ยอดที่ต้องเรียกเก็บจากลูกค้า** เหมือนค่างวด → อยู่ในระบบใบแจ้งหนี้เดียวกัน

## ระบบที่ต้องจับตาตอนออกแบบ Data Lake

| ระบบ | ประเด็น |
|---|---|
| **Gtrack Smarth** | GPS = **time-series ขนาดใหญ่มาก** ต้องประเมินปริมาณ/ความถี่ก่อนตัดสินว่าจะ ingest ระดับไหน (ทุกจุด? สรุปรายวัน?) |
| **365 / D365** | ยังไม่ชัดว่าเป็นตัวเดียวกับ `D365FO_DATALAKE` ที่เห็นใน SQL หรือไม่ `[อนุมาน]` → [[Other Systems]] |
| **Ev7core** | เป็นจุดรวม API ของทุกระบบ — อาจ ingest จากที่นี่ที่เดียวได้ แทนที่จะต่อทีละระบบ **ต้องยืนยัน** |
| **GI Core vs Ev7core** | ความสัมพันธ์ยังไม่ชัด — เป็นระบบต่อยอด หรือกำลังแทนที่กัน |

## หมวดที่ยังไม่มีระบบรองรับ

| หมวด | สถานะ |
|---|---|
| **Risk** — Rule Config · Risk Alerts · Risk Analytics | **ไม่มีทั้งหมวด** — เป็นช่องว่างที่ Data Lake ช่วยได้โดยตรง |
| **MKT** — Campaign Hub · Banner · Promo | ทีม MKT ทำนอกระบบ EV7 |
| Freeze Leads | ไม่มีที่พักลีดที่รอเอกสาร/ติด background check |
| 3rd-party Valuation API | ยังไม่ทำ trade-in รับเป็นเงินดาวน์ |
| OCR · SMS · Push Notification | ทีมระบุว่า *"ทำได้เลย"* ติดที่การตัดสินใจทางธุรกิจ |
