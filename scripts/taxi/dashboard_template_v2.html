ภาพถนน Mapillary (ไม่บังคับ)

ใส่ token เพื่อแสดงภาพถนนจริงของจุดที่รถจอดในหน้านี้เลย ถ้าไม่ใส่ ยังกดลิงก์ไปดู Street View / Mapillary ได้ตามปกติ
  1. สมัครฟรีที่ mapillary.com
  2. ไปที่ Dashboard → Developers → Register application
  3. คัดลอก Client Token (ขึ้นต้นด้วย MLY|) มาวางด้านล่าง
token เก็บในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ติดไปกับไฟล์เวลาส่งต่อ
